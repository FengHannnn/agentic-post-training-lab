# 首轮正式 DPO v1

日期：2026-11-02（Asia/Shanghai）。用户选择：先只跑 DPO，使用已复核的 44 对偏好完成小规模训练与前后评测。

## 输入与训练

数据来自冻结 SFT 在 train 分区采集的 48 条随机轨迹，保留 44 对同上下文偏好，覆盖 12 个任务。chosen 为脚本生成并经环境验证的 SQL；rejected 是模型实际失败动作。pairs.jsonl SHA-256：508464a0314982c7e6ade95c57afa3be081afc80f237e4fb20c8abe2079ffb78。

| 项目 | 配置 |
|---|---|
| 起点 | 已冻结的 126-step SFT |
| adapter SHA-256 | e41bef8a51d8d968bcfee4a606da364888a191c4e1ee85399215bc12b85813f0 |
| 优化器 | 新建 AdamW，weight_decay=0 |
| 学习率 / beta | 5e-6 / 0.1 |
| 训练量 | 44 对，一遍，每 4 对梯度累积，11 次更新 |
| 训练精度 | FP32，LoRA q_proj/v_proj，梯度检查点 |
| 动作概率 | response token logprob 求和，包含 EOS |
| reference | 同一 SFT 在任何更新前的 FP32 分数，detach 后按完整 token 输入摘要绑定 |
| 梯度裁剪 | norm=1 |
| 检查点 | 第 4、8 步和 final；保存 adapter、Adam、进度与 RNG |

本轮使用独立 DPO Adam 计数 1→11，SFT 的 126 步作为来源记录，原 SFT adapter 保持固定。reference 先从起始策略计算并缓存，后续优化时只读取绑定的固定分数。记录训练前后相对 reference 的偏好 margin，以及 chosen/rejected 的平均 token logprob。

## 前后评测

在相同引擎设置下比较冻结 SFT 和 DPO：

- greedy：每个模型执行 train 12 + development 4，共 32 条。
- 随机评测：每个模型执行 train 12 × 4 条，共 96 条；temperature=0.8，使用新 seed=2026110211，两模型共享相同任务和种子安排。
- 总计 128 条完整轨迹，全部执行 CPU token/环境重放审计。

主要指标为随机成功、故障恢复、有效 SQL、错误类型、输出 token 和 greedy 行为保持。原始采样成功 23/48 作为历史记录，本轮主要对照采用新 seed 下重新运行的 SFT 与 DPO。独立 test 的首次结果继续保留，本轮不新增 test 评测。

DPO 输出为独立候选，共同 SFT 基线保持原样。chosen-only SFT 控制分支留作后续选项。

## 云端运行

上传 v2-dpo-train-v1-20261102.zip 到 /root/rivermind-data/ 后执行：

```bash
conda activate /root/rivermind-data/envs/apt-vllm
cd /root/rivermind-data
ls -lh /root/rivermind-data/v2-dpo-train-v1-20261102.zip
unzip -o /root/rivermind-data/v2-dpo-train-v1-20261102.zip -d /root/rivermind-data/AgenticPostTrainingLab
cd /root/rivermind-data/AgenticPostTrainingLab/v2
python scripts/run_v2_dpo.py
```

入口依次运行 train、greedy、sample、audit，总预算 5400 秒并预留打包时间。查看训练或随机评测进度：

```bash
tail -f /root/rivermind-data/AgenticPostTrainingLab/v2/artifacts/dpo-train-v1-20261102/train.log
# 进入 sample 阶段后：
tail -f /root/rivermind-data/AgenticPostTrainingLab/v2/artifacts/dpo-train-v1-20261102/sample.log
```

回传：/root/rivermind-data/AgenticPostTrainingLab/v2/dpo-train-v1-20261102-review.zip。

回传包含 final adapter、配置、参考分数、前后评分、128 条评测轨迹、统计和日志。中间权重和 Adam 状态留在云端原输出目录，减少下载体积。入口要求新的输出目录，失败时保留已有证据并打包。
