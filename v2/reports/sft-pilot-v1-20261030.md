# V2 首轮 SFT：实现与运行说明

更新：2026-10-30（Asia/Shanghai）。

首轮 SFT 数据、LoRA 训练入口、开发集评测和云端运行包已完成。本地 V2 测试 **52 passed**。下一步在已验证的 4090D 环境运行训练包，再回传 review ZIP 核查实际效果。

## 数据与监督

仅使用现有 train-000 至 train-011，共 12 个训练任务。每个任务生成标准专家、SQL 表名修复、证据引用修复三条轨迹，共 36 条；全部在环境中执行并重放成功。30 条轨迹包含成功恢复，42 次错误动作保留为后续决策上下文。

共生成 252 个正确动作样本、18,480 个监督 token。用户请求、历史动作和工具观察进入 prompt；当前正确 assistant 动作及 EOS 进入 loss。错误动作与失败检查排除监督。工具反馈沿用 runtime 的 user-role observation 格式。示范来源为脚本专家，development/test 留作评测。

真实 Qwen chat template 下，上下文最短 324、中位 920、最长 1,430 token。训练上限 2,048；超过上限时显式停止并记录错误，保留完整证据链。

## 首轮配置

| 项目 | 配置 |
|---|---|
| 模型 | Qwen/Qwen2.5-1.5B-Instruct |
| 固定 revision | 989aa7980e4cf806f80c7fef2b1adb7bc71aa306 |
| LoRA | q_proj/v_proj，r=8，alpha=16，dropout=0 |
| 训练精度 | FP32，SDPA，梯度检查点 |
| 学习率 / 优化器 | 5e-5 / AdamW，weight_decay=0 |
| 训练量 | 两遍、504 个动作曝光，8 个动作梯度累积，预计 63 次更新，上限 64 次 |
| 损失 | 每个动作内 token mean，再对累积动作求平均 |
| 梯度裁剪 | norm=1 |
| 随机种子 | 2026103001 |
| 时间预算 | 5,400 秒，训练与评测共享，预留打包时间 |
| 检查点 | 每 8 次更新及 final；保存 adapter、Adam、进度、Python/Torch/CUDA RNG |

这些参数用于首轮小规模试跑。运行中记录 loss、梯度范数、实际显存峰值、参数变化和更新步数。训练只投影监督后缀到词表，减少长上下文的 logits 显存。实际 1.5B 容量与训练效果随云端回传核验。

## 评测与回传

训练结束后退出训练进程，再用 vLLM BF16 加载 final LoRA，沿用原始 baseline 的 4 个 development 任务和 greedy 设置：seed=2026102901，8192 上下文，每动作 256 token，每任务 12 轮。

原始 baseline 为成功 0/4、故障恢复 0/2、严格格式 26/48。新评测记录成功、恢复、严格格式、有效 SQL、验证进度、有效检查、工具错误、轮数、生成 token 和完整逐轮轨迹。

运行包独立校验发布文件、模型文件和检查点摘要。每次运行要求新的输出目录。失败或超时后仍生成日志、状态和 review ZIP；已完成检查点保留，后续可按输入摘要恢复。

## 云端运行

将 v2-sft-pilot-v1-20261030.zip 上传到 /root/rivermind-data/，然后执行：

```bash
conda activate /root/rivermind-data/envs/apt-vllm
cd /root/rivermind-data
ls -lh /root/rivermind-data/v2-sft-pilot-v1-20261030.zip
unzip -o /root/rivermind-data/v2-sft-pilot-v1-20261030.zip -d /root/rivermind-data/AgenticPostTrainingLab
cd /root/rivermind-data/AgenticPostTrainingLab/v2
python scripts/run_v2_sft.py
```

终端会打印每阶段状态与日志路径。需要查看训练进度时，在另一个终端执行：

```bash
tail -f /root/rivermind-data/AgenticPostTrainingLab/v2/artifacts/sft-pilot-v1-20261030/train.log
```

回传文件：/root/rivermind-data/AgenticPostTrainingLab/v2/sft-pilot-v1-20261030-review.zip。

运行沿用现有模型缓存和 Python 环境。报告生成后提供链接，按用户要求保持关闭。
